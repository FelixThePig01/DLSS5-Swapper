# DLSS 5 Swapper

**DLSS 5 Swapper** swaps the nvngx dll in titles still on 3 / 4 / 4.5. Neural upscale and frame gen on the current driver. RenoDX and ReShade load after the swap if you want them.

## How to use
1. Run as admin so it can see the game folder.
2. Pick the title.
3. Swap. Launch. Set Quality / Performance in the game menu.
4. Optional: load RenoDX or ReShade after.

## FAQ

**How to enable?**
Swap, then turn it on in the game menu.

**AMD?**
No native Tensor path. Swapper refuses.

**Is it AI?**
Neural rendering, not a sharpen slider.
